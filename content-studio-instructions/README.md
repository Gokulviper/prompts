# Content Studio Instruction Pack

This pack contains five Markdown instruction files:

- `CLAUDE.md` — shared master rules, project boundaries, factual accuracy, media handling, and YouTube originality/monetization safeguards.
- `instructions/PROJECT-1-AI-VIDEO-STUDIO.md` — AI voice + animation + synchronized subtitles.
- `instructions/PROJECT-2-SILENT-ANIMATION-CLIP-STUDIO.md` — silent visuals-only clips; no narration, subtitles, captions, added text, music, or SFX by default.
- `instructions/PROJECT-3-INTERACTIVE-ANIMATION-STUDIO.md` — manually controlled reusable animations and personal voice recording.
- `instructions/PROJECT-4-AI-ANIMATED-HTML-EXPLAINER.md` — AI-generated interactive HTML explainers from arbitrary topics and source media.

## Suggested placement

Put `CLAUDE.md` at the root of your workspace. Keep the `instructions/` directory beside it. When starting work on a project, tell Claude Code to read the matching project instruction file before editing code.

These instructions are production guidance, not a guarantee that YouTube will approve monetization. Re-check YouTube's current official policies before publishing.
